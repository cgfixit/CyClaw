# Handoff checklist

- Final diff matches requested scope. Record base/head and any open-PR overlap.
- Evidence covers the changed path and applicable invariants. Label mocks, skips and exact-head CI.
- Owning docs, skill metadata and references match the candidate.
- Stage intended files only. Exclude private data, credentials, indexes, logs and history.
- Validate the PR body, including merge order, human-review notes, ELI5 and timestamp. Follow the [Codex workflow](../Codex_instructions.md).
