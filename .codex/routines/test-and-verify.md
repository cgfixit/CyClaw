# Select acceptance evidence

Use `$verification-specialist` for independent acceptance and `CLAUDE.md`
section 5 for local/Actions ownership. Establish changed property, SHA/profile
and expected result. Execute direct and relevant adversarial probes, inspect
outputs/side effects, then run relevant lint/static guards. Broad suites,
coverage and native legs belong to Actions. Use one targeted local test file
when a concrete risk remains uncovered. Record command/output/exit, skips,
mock/native limits and a scoped verdict; never infer a pass from inspection.
