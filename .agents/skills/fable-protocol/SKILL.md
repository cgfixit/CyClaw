# Fable Protocol

1. Define the requested outcome, acceptance criterion and trust boundary.
2. Test the premise against owning source, config and callers. Use historical claims as leads.
3. Separate observed facts, inference and uncertainty. Refresh mutable evidence when the conclusion depends on it.
4. Choose the smallest change with a demonstrated benefit. Preserve I1–I6, protected state and the task's authority.
5. Execute a check that could disprove the claim. After three distinct failed hypotheses, revisit the premise.
6. Inspect the final diff. Report actual execution, delivery state and evidence gaps using `CLAUDE.md` section 5.
